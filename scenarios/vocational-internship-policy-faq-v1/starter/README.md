# 职业学校学生实习政策问答助手

你需要完成一个带来源引用的政策问答程序。系统只允许使用任务目录中的权威资料，不能依靠模型常识猜测政策结论。

## 本轮任务

实现 `faq_app.py` 中的 `retrieve(question, sources)`：

1. 典型实习权益问题能够命中相关资料；
2. 返回结果保留发布机关、来源链接和适用范围；
3. 资料外问题返回空结果，不编造政策；
4. 江苏实施细则不能表述成全国统一规则。

## 课程思政融入点

- **法治意识**：以现行有效规则为依据，区分规则层级和适用范围。
- **诚实守信**：资料不足时明确说明未知，不生成貌似合理的结论。
- **职业责任**：让使用者能够复核来源，对系统输出负责。
- **权益意识**：理解技术系统的错误回答可能影响学生对实习权利的判断。
- **工匠精神**：通过可复现测试、清晰代码和资料更新说明保证交付质量。

这些目标通过程序行为、引用质量、调试解释和边界测试观察，不按口号表述单独计分。

保存代码、创建检查版本后运行验收。若未通过，先阅读证据并写下你的判断，再请求分层指导。
