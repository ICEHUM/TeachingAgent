# Stage 06B 真实课堂场景与智能体必要性验证

日期：2026-09-21

## 结论

本轮没有把另一组示例文案替换进旧任务，而是新增了独立的真实来源场景包，并实际导入 DEMO PostgreSQL。旧 FAQ 演示、旧 Attempt 和旧工作区均保留。

当前系统仍不是任意课程的通用导入平台。本轮能力边界是：经过服务端校验的一个版本化场景包，可以幂等导入为独立 TaskVersion、RequirementDefinition、RubricDefinition、Attempt 与工作区，并选择与该 TaskVersion 匹配的服务端工具测试。

## 场景

- 场景：职业学校学生实习政策问答助手
- Task：`POLICY-FAQ-001-v1`
- 面向课程：AI 应用开发实训
- 学情：已具备 Python 基础
- 真实来源：
  - 教育部等八部门《职业学校学生实习管理规定（2021年修订）》
  - 教育部职业教育与成人教育司负责人答记者问
  - 江苏省职业学校学生实习管理实施细则
- 学生交付：完成结构化政策资料检索，保留发布机关、来源链接和适用范围，对资料外问题返回空结果。

## 课程思政融入

| 育人目标 | 专业任务行为 | 可观察证据 | 评价边界 |
|---|---|---|---|
| 法治意识 | 使用现行有效规定回答 | source、authority、version | 不按口号评分 |
| 权益意识 | 处理强制实习、夜班、报酬等真实问题 | 命中结果与回答依据 | 不让模型代替法律判断 |
| 诚实守信 | 资料外问题拒绝编造 | unknown question test | 未知不等于学生失败 |
| 职业责任 | 保留来源和适用范围 | citation、scope | AI建议不进入正式成绩 |
| 工匠精神 | 可复现测试和资料更新说明 | tests、README、Snapshot | 只评价可核对行为 |

课程思政进入任务目标、数据字段、自动测试、迁移任务、学生解释和教师量规。页面不增加口号区，正式成绩仍由教师依据量规和证据确认。

## 真实失败闭环

1. 为起始代码创建 Snapshot A：`b70c8797-50c5-497f-8611-4739baf5cc7f`。
2. OpenHands 在独立工作区执行 `POLICY-FAQ-001-v1` 服务端测试。
3. 资料加载成功，起始代码的 `retrieve` 固定返回空列表，典型实习问题未命中。
4. Requirement `retrieval_public_tests` 写入 `NOT_SATISFIED`，绑定 Snapshot A、operation 与 artifact。
5. 学生失败次数从 0 变为 1；基础设施失败仍为 0。
6. LangGraph选择 L0，不提供代码补丁。
7. DeepSeek依据服务端任务上下文询问问题文本、keywords、来源机关和适用范围，没有臆造向量索引或外部知识库。
8. 学生观察写入业务事件并满足本阶段解释项。
9. 再次请求指导时，模型输入继承 Snapshot A 的 RequirementResult 与 Evidence refs；输出绑定 artifact 和学生观察事件。

## 智能体必要性判断

如果系统只显示固定测试通过或失败，智能体没有存在必要。当前真实链路开始体现的额外价值是：

- 把一次执行失败绑定到任务版本、Snapshot、Requirement 和可追溯证据；
- 根据教学模式和帮助级别限制指导范围；
- 将政策场景的专业边界作为服务端上下文，而不是让模型自由猜测；
- 要求学生先形成观察，再逐级提升帮助；
- 把重复失败和已有帮助整理为教师介入事实。

这些能力只证明技术合同成立，还没有证明学习成效。下一步课堂试用需要比较“固定测试反馈”和“证据驱动分层指导”，记录学生独立定位比例、提示层级、教师介入、完成时间、变式任务和教师观察，不预先填写成效数字。

## 未完成和风险

1. 当前只支持 `FAQ-001-v1` 和 `POLICY-FAQ-001-v1` 两个服务端工具配置，尚不是任意任务导入器。
2. 正式课堂应从第一阶段开始；本次验证入口从第三阶段开始，只用于快速检验教学闭环。
3. 场景资料采用权威来源的结构化教学摘要和官方链接。正式开课前，教师仍需复核当时有效版本和本地适用范围。
4. 法律政策问答必须保留“资料不足无法判断”的边界，不能把模型输出当成正式法律意见。
5. Agent Server 与学生进程同 UID 仍是开放多租户任意代码课堂前的安全阻断项。
6. 尚无真实学生试用数据，因此不能声称提高了学习效果或降低了教师工作量。
