# Impeccable Final Critique

模式：**Operate**。审查对象是学生和教师完成教学任务的工作台，优先级依次为任务可见性、状态可辨识、操作确定性、证据可追溯、视觉一致性。

## 结论

- P0：0 项。
- P1：首轮发现 3 项，全部修复。
  - 教师低样本队列在仅 1 名学生时留白缺少解释：增加队列排序说明，保留注意力在唯一待介入学生。
  - 教师评价页存在浏览器继承的小于 12px 文本：正式页面统一 `small >= 12px`。
  - Monaco IME 辅助输入框在截图中可见：保持编辑器行为并将辅助 textarea 视觉透明。
- P2：无阻断项。390×844 继续遵循产品边界，只保证任务查看、指导查看、求助和教师介入可用，不将其扩展为完整移动 IDE。

## Heuristic review

| 维度 | 结果 | 证据 |
|---|---|---|
| 层级 | 通过 | 学生编辑器居中，教师待介入队列优先，Evidence 先结论后追溯 |
| 认知负荷 | 通过 | 右侧教练拆为当前判断、检查方向、下一步；教师操作拆为说明、策略、流程控制 |
| 一致性 | 通过 | Button、Badge、Tabs、Input、Snapshot、Requirement、Score 使用共享 tokens |
| 教学语义 | 通过 | AI 建议标注“仅供参考”，正式成绩只出现在教师确认区 |
| 可访问性 | 通过 | 4 视口无横向溢出；可见控件均有名称；元信息不低于 12px；焦点可见 |
| 动效 | 通过 | 仅使用短时状态过渡并支持 reduced motion |
| 反模式 | 通过 | detector 返回 `[]`；没有渐变、发光 AI 卡片、玻璃拟态或聊天窗口主体 |
