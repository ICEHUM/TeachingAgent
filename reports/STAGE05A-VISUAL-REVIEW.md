# Stage 05A 编码前视觉审查记录

日期：2026-09-20
界面：学生实训工作台、教师课堂工作台
模式：Impeccable `Operate`
基准视口：1440×900；验证视口：1366×768、1280×800

## Design Read

这是面向高职 AI 应用开发实训的双角色复杂工作台。界面服务高频编码、验收和课堂介入，采用接近 GitHub、Linear、VS Code 的克制开发工具语言；设计方差 4、动效 2、信息密度 8。视觉表达服从任务效率、状态可信度和证据可追溯性。

## 采用的 Impeccable 建议

- 使用 Operate 模式，以熟悉、稳定的工作台结构承载高频任务，不用品牌页构图。
- 产品界面使用紧凑固定字号、系统字体、明确边界和一个克制强调色。
- 学生端保持任务/阶段、编辑器/运行结果、实训教练三块稳定区域；教师端首先回答“现在谁需要我帮助”。
- loading 使用骨架或保留上下文的行内状态；错误说明具体问题和恢复动作。
- 所有交互提供 hover、focus、active、disabled、loading、error 状态；焦点环、文本选择、滚动条和数字排版纳入设计系统。
- 动效只解释抽屉、运行状态和保存状态变化，持续 120–180ms，并支持 `prefers-reduced-motion`。
- Evidence 和 Intervention 使用不离开上下文的固定侧栏；不为普通操作增加模态窗口。
- 以真实长文本、超时、旧 Snapshot、模型 fallback、SSE 重连和版本冲突检验布局。

## 拒绝或调整的 Impeccable 建议

- 不采用“大而大胆”的品牌表达、视觉奇观或营销首屏；本产品的可信度来自信息结构和真实状态。
- 不运行新视觉世界的概念竞赛：根 DESIGN.md 已确定浅色工作台、蓝色强调和双端布局，Stage 05A 是该系统的正式实现。
- 不为窄屏构建完整移动 IDE；小于 1024px 改为任务/指导可用的分区切换，并明确编码需要电脑。
- 不使用装饰性图片或生成式插画；实训内容本身是主视觉。

## Taste 复核

Taste 自述适用于落地页、作品集和重设计，并明确“不适用于 dashboards / multi-step product UI”。因此本阶段只采用：

- 避免 AI 紫色渐变、玻璃拟态、三等分模板卡和过量圆角。
- 不使用 emoji/Unicode 代替图标；图标采用一致的内联 SVG。
- 遵循已有 DESIGN.md 与业务语义，不把个人审美覆盖产品事实。

拒绝：

- 默认 `DESIGN_VARIANCE: 8`、`MOTION_INTENSITY: 6` 和低密度落地页节奏。
- Hero、品牌故事、营销 CTA、作品集式非对称构图和大幅图片。
- 依靠视觉冲击削弱工作台的扫描顺序。

## 信息架构决定

### 学生端

1. 顶栏：课程/任务、当前阶段、Snapshot、保存与运行状态、保存、创建 Snapshot、运行检查。
2. 左栏：任务目标、六阶段、当前阶段 Requirement 定义与满足进度。
3. 中区：文件树 + Monaco；下区为运行结果、验收项、成果预览。
4. 右栏：当前观察、Evidence、本轮指导、学生观察、下一步行动；不是聊天窗口。
5. Evidence Drawer：从 Requirement 行打开，展示脱敏结构化证据。

### 教师端

1. 左侧列表：需要关注、进行中、已完成；需要关注默认展开并位于首屏。
2. 中区：选中学生的事实摘要、Requirement 和教学过程。
3. 右侧 Intervention 栏：Evidence、学生观察、指导历史、Snapshot 摘要和真实 resume 操作。
4. 智能体运行轨迹：只将已有 TeachingEvent 转换为学生行为 → OpenHands → RequirementEvaluator → LangGraph → DeepSeek。

## 视觉系统决定

- 浅灰页面、白色编辑与详情表面、冷灰边界；面板主要靠 1px 边界区分。
- 蓝色只用于当前选择、焦点和主操作；成功/警告/错误均配图标和文字。
- 控件半径 6px、面板 10px、抽屉 12px；不使用全局胶囊。
- 阴影仅用于悬浮抽屉，常驻区域无阴影。
- 代码区使用 Monaco 原生编辑体验，其他区域使用系统中文字体。

## 发布前验证契约

- 三个桌面视口各截图一次，修复高优先级问题后再截图一次。
- 验证从任务到编辑、保存、Snapshot、运行、Evidence、指导和阶段推进的真实浏览器链路。
- 验证教师打开 Intervention、查看过程、允许 L2/暂停指导并恢复。
- 验证键盘主路径、抽屉关闭后焦点归还、状态文字、减少动画和窄屏降级。
- 运行 Impeccable detector、发布前 critique；Taste 只做反模板化视觉复核。
